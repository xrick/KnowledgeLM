### 第一部分：LLM 基礎架構與原理

**1. 問：什麼是 Transformer 架構，為什麼它對現代 LLM 很重要？**
答：Transformer 架構是現代 LLM（如 GPT-4）的基礎。與早期的 RNN 不同，它不依賴順序處理數據，而是利用「自注意力機制（Self-Attention）」並行處理序列中的所有部分，這大大加快了訓練速度並能更好地捕捉長距離的依賴關係。

**2. 問：在 LLM 中，「標記化（Tokenization）」的作用是什麼？**
答：標記化是將原始文本轉換為模型可以理解的數值序列的過程。它將文本分解為「Token」（可以是單詞、子詞或字符）。這會影響模型的效率、詞彙量大小以及處理不同語言的能力。

**3. 問：什麼是嵌入（Embeddings）？**
答：嵌入是將離散的 Token 轉換為連續向量的過程。這些向量在多維空間中捕捉詞彙的語義和句法含義，使得語義相似的詞在空間中距離更近。

**4. 問：什麼是「注意力機制（Attention Mechanisms）」？**
答：注意力機制允許模型在生成輸出時，動態地權衡輸入序列中不同部分的重要性。它讓模型能夠「關注」與當前上下文最相關的單詞，從而生成更連貫的文本。

**5. 問：RNN（遞歸神經網絡）在處理長序列時有什麼主要限制？**
答：RNN 存在「梯度消失（Vanishing Gradient）」問題，這使得它們難以捕捉長序列中的依賴關係。此外，RNN 需要按順序處理數據，限制了並行計算的能力，導致訓練效率較低。

### 第二部分：決策與生成

**6. 問：LLM 如何決定下一個生成的詞？**
答：LLM 本質上是概率模型。它根據前面的上下文，計算詞彙表中所有可能 Token 的概率分佈，然後使用如 Softmax 等函數選擇概率較高（或根據採樣策略選擇）的 Token 作為下一個輸出。

**7. 問：什麼是「幻覺（Hallucination）」或模型的不確定性？**
答：這是指模型生成聽起來合理但實際上不正確或無意義的內容。這通常源於訓練數據的稀疏性、上下文的歧義性，或者模型試圖填補其知識空白。

**8. 問：在生成文本時，什麼是「貪婪解碼（Greedy Decoding）」？**
答：貪婪解碼是一種簡單的選擇策略，模型在每一步都選擇概率最高的那個 Token。雖然簡單，但它容易導致重複性或陷入局部最優解，缺乏創造性。

**9. 問：什麼是 Beam Search？**
答：Beam Search 是一種比貪婪解碼更高級的生成策略。它在每一步保留多個（Beam width）高概率的候選序列，最終選擇整體概率最高的序列，通常能生成更連貫的文本。

### 第三部分：訓練與微調

**10. 問：訓練 LLM 的第一步「數據收集」需要注意什麼？**
答：數據收集需要確保數據的多樣性、範圍和質量。數據應涵蓋廣泛的主題、風格和語言，同時要注意版權、隱私和偏見問題。

**11. 問：什麼是「遷移學習（Transfer Learning）」？**
答：遷移學習是指將在大規模數據集上預訓練的模型（已學習通用語言特徵）應用於新的、通常數據較少的特定任務。這比從頭訓練模型更高效。

**12. 問：什麼是「課程學習（Curriculum Learning）」？**
答：這是一種模仿人類學習過程的訓練策略，即先讓模型學習簡單的任務或數據，然後逐漸增加難度。這有助於模型更快收斂並提高泛化能力。

**13. 問：LoRA（Low-Rank Adaptation）在微調中有什麼優勢？**
答：LoRA 是一種高效微調技術。它不更新模型的所有參數，而是通過低秩分解只更新一小部分參數。這大大降低了微調所需的計算資源和內存，使得在消費級硬件上微調大模型成為可能。

**14. 問：什麼是 RLHF（Reinforcement Learning from Human Feedback）？**
答：RLHF 是利用人類反饋進行強化學習的技術。通過人類對模型輸出的排序或評分，訓練一個獎勵模型，然後用該獎勵模型來優化 LLM，使其輸出更符合人類的價值觀和偏好。

**15. 問：什麼是災難性遺忘（Catastrophic Forgetting）？**
答：這是指模型在學習新任務時，完全忘記了之前學習過的任務知識。持續學習（Continual Learning）模型旨在通過回放機制或正則化等方法來解決這個問題。

### 第四部分：測試與評估

**16. 問：什麼是困惑度（Perplexity）？**
答：困惑度是用於評估語言模型的定量指標，衡量模型預測下一個 Token 的不確定性。困惑度越低，表示模型的預測能力越好。

**17. 問：BLEU 分數主要用於評估什麼？**
答：BLEU 分數主要用於評估機器翻譯的質量。它通過比較機器生成的文本與人類參考翻譯之間的 n-gram 重疊程度來計算分數。

**18. 問：為什麼需要「人機迴路（Human-in-the-loop）」評估？**
答：自動化指標（如 BLEU）無法完全捕捉語言的細微差別、文化背景或情感。人類評估者可以提供關於連貫性、相關性和道德性的定性反饋，這對於高質量的 LLM 至關重要。

### 第五部分：部署與優化

**19. 問：在部署 LLM 時，API 集成與嵌入式集成有什麼區別？**
答：API 集成是通過網絡調用外部服務商的模型，易於擴展但存在延遲和數據隱私問題；嵌入式集成是將模型直接運行在本地基礎設施上，延遲低、數據控制權高，但需要強大的硬件支持。

**20. 問：什麼是量化（Quantization）？**
答：量化是一種優化技術，將模型參數的精度從高精度（如 32 位浮點數）降低到低精度（如 8 位整數）。這能顯著減小模型體積並加快推理速度，同時儘量減少精度損失。

**21. 問：什麼是剪枝（Pruning）？**
答：剪枝是移除神經網絡中對輸出影響極小或無影響的權重（參數）。這可以創建更稀疏的模型，減少計算量並提高效率。

**22. 問：什麼是知識蒸餾（Knowledge Distillation）？**
答：知識蒸餾是指訓練一個較小的「學生模型」來模仿一個較大的「教師模型」的行為（輸出概率分佈）。這允許在資源受限的設備（如手機）上部署性能接近大模型的高效模型。

**23. 問：GPU 中的 Tensor Cores 對 LLM 有什麼作用？**
答：Tensor Cores 是專為深度學習設計的硬件單元，能加速矩陣乘法運算。它們支持混合精度計算，能大幅提高 LLM 訓練和推理的吞吐量。

### 第六部分：安全、倫理與法律

**24. 問：什麼是 LLM 的對抗性攻擊（Adversarial Attacks）？**
答：這是指惡意輸入被設計用來欺騙模型，使其產生錯誤、有偏見或有害的輸出。例如，通過微小的文本擾動讓模型繞過安全過濾器。

**25. 問：為什麼 LLM 會有偏見？如何緩解？**
答：LLM 的偏見通常來自於訓練數據中存在的社會偏見。緩解策略包括：精心策劃多樣化的數據集、在訓練中使用去偏見算法、以及通過 RLHF 進行人工修正。

**26. 問：使用 LLM 生成內容會面臨哪些知識產權（IP）挑戰？**
答：主要挑戰包括：AI 生成的內容是否受版權保護（目前多數法律傾向於否）、以及使用受版權保護的數據訓練模型是否構成侵權。

**27. 問：GDPR 對 LLM 的部署有什麼影響？**
答：GDPR 要求保護個人數據隱私，並賦予用戶解釋權。這意味著 LLM 開發者必須確保訓練數據的合法性，實施數據匿名化，並努力提高模型的可解釋性。

### 第七部分：未來展望

**28. 問：未來的多模態（Multimodal）LLM 是什麼樣子的？**
答：多模態 LLM 不僅能處理文本，還能理解和生成圖像、音頻和視頻。這將允許更豐富的交互，例如根據文本描述生成視頻，或根據圖片回答複雜問題。

**29. 問：GPT-5 或下一代模型預計會有哪些改進？**
答：預計會有更強的上下文理解能力（長期記憶）、更高效的推理速度、更強的邏輯推理和解決問題能力，以及更高的個性化和更強的數據隱私保護。

**30. 問：LLM 在醫療領域的應用潛力是什麼？**
答：LLM 可以協助診斷（分析病歷和文獻）、制定個性化治療方案、簡化行政工作（如自動生成報告），以及作為患者的健康助手提供諮詢。但這需要極高的準確性和隱私保護。
