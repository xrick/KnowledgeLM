5. 快速修改範例
================================================================================

【範例 1: 修改 "個來源" 為 "個技能庫"】

在 ui_translations.json:
  "sources_count": "{count} 個技能庫"

在 skill_main.html Line 1357:
  pageTitle.textContent = `${totalItems} 個技能庫 (${totalItems} 項)`;

【範例 2: 修改統計卡片標籤】

在 ui_translations.json:
  "config": {
    "stats": {
      "skills": "知識技能",
      "documents": "PDF 文件",
      "total_chunks": "文字區塊"
    }
  }

================================================================================
6. 注意事項
================================================================================

1. 優先修改 ui_translations.json - 這樣中英文都會更新
2. 如果 ui_translations.json 沒有對應的 key，需要同時修改 HTML
3. 修改後重新整理瀏覽器即可看到效果（不需重啟伺服器）
4. 使用瀏覽器開發者工具 (F12) 可以快速找到元素 ID

7. 常用搜尋指令
================================================================================

# 搜尋特定文字
grep -rn "個來源" template/
grep -rn "Documents" template/

# 搜尋翻譯 key
grep -rn "t('config" template/

# 搜尋元素 ID
grep -rn "id=\"stat-" template/
