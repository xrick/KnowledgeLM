## 七、後端 Python — Progressive Streaming（OPMP 串流）

| 檔案 | 目的 |
|------|------|
| `app/SkillServices/progressive_skill_streaming/progressive_streaming.py` | 5 階段串流主協調器 |
| `app/SkillServices/progressive_skill_streaming/phase1_skill_query_understanding.py` | Phase 1: 查詢理解與意圖分析 |
| `app/SkillServices/progressive_skill_streaming/phase2_skill_retrieval.py` | Phase 2: 並行向量檢索 |
| `app/SkillServices/progressive_skill_streaming/phase3_context_assembly.py` | Phase 3: 上下文組裝 |
| `app/SkillServices/progressive_skill_streaming/phase4_response_generation.py` | Phase 4: Token-by-token 串流生成 |
| `app/SkillServices/progressive_skill_streaming/phase5_postprocessing.py` | Phase 5: 後處理與歷史儲存 |

### OPMP 5 階段架構

```
Phase 1: Query Understanding      # 問題理解與擴展
Phase 2: Parallel Retrieval       # 並行向量檢索
Phase 3: Context Assembly         # 上下文組裝
Phase 4: Response Generation      # 逐字串流輸出
Phase 5: Post Processing          # 後處理與歷史記錄
```

## 十二、資料庫與向量索引（Runtime Data）

### SQLite 資料庫

| 檔案 | 目的 |
|------|------|
| `data/docai.db` | **File-Based 系統 SQLite**（檔案 metadata） |
| `data/skill_metadata.db` | **Skill 系統 SQLite**（5 張表：skill_heads、skill_metadata、skill_document_mapping、skill_chunk_metadata、processing_jobs） |

### FAISS 向量索引

| 目錄 | 目的 |
|------|------|
| `data/faiss_indices/file_*/` | File-Based FAISS 向量索引（每個檔案一個目錄） |
| `data/faiss_indices/skills/skill_*/` | Skill-Based FAISS 向量索引（每個 document 一個目錄） |

### 索引結構

每個 FAISS 索引目錄包含：
- `index.faiss` — FAISS 向量索引檔案
- `index.pkl` — Docstore metadata（chunk 內容與映射）
