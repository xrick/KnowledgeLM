## 詳細診斷結果

### 1. 向量資料庫配置問題

#### 1.1 問題描述

系統配置檔指定使用 Milvus 作為向量資料庫後端,但:

1. **Milvus 服務未運行**
   - 預期端點: `localhost:19530`
   - 實際狀態: 連接失敗

2. **代碼實現不一致**
   - 主要代碼使用 FAISS (`app/Providers/vector_store_provider/client.py`)
   - Milvus 客戶端已實現但未整合 (`app/Providers/vector_store_provider/milvus_client.py`)

3. **配置檔設定**
   ```python
   # app/core/config.py:151
   VECTOR_STORE_BACKEND: str = "milvus"  # ← 配置為 Milvus
   ```

#### 1.2 根本原因分析

**架構演進問題**:
- 系統最初設計使用 FAISS (內存向量儲存)
- 後續添加 Milvus 支援用於企業部署
- 配置檔預設值設為 "milvus",但開發環境未啟動 Milvus 服務
- 代碼中 `VectorStoreProvider` 主要實現 FAISS 邏輯

**代碼證據**:

`app/Providers/vector_store_provider/client.py:76-89`:
```python
if self.backend == "faiss":
    # Create FAISS vector store
    vector_store = FAISS.from_texts(
        texts=texts,
        embedding=embeddings,
        metadatas=metadatas
    )
    ...

elif self.backend == "chroma":
    # ChromaDB implementation
    ...
```

注意: 沒有 `elif self.backend == "milvus"` 的分支!

#### 1.3 影響範圍

**文檔上傳流程** (`app/api/v1/endpoints/upload.py`):
```
上傳 PDF
  ↓
處理文件 (input_data_handle_service)
  ↓
向量化 (embedding_provider)
  ↓
儲存向量 (vector_store_provider) ← **這裡會失敗**
  ↓
儲存元資料 (file_metadata_provider)
```

**預期錯誤**:
- 如果 `VectorStoreProvider.__init__(backend="milvus")` 被呼叫
- 但 `create_store_from_texts()` 中沒有 Milvus 分支
- 系統將拋出 `ValueError: Unsupported backend: milvus`

#### 1.4 修復方案

**方案 A: 使用 FAISS (推薦用於開發環境)** ⭐

優點:
- 無需額外服務
- 快速啟動
- 適合開發和測試

步驟:
1. 修改 `app/core/config.py:151`:
   ```python
   VECTOR_STORE_BACKEND: str = "faiss"  # 改為 "faiss"
   ```

2. 或創建 `.env` 檔案:
   ```bash
   VECTOR_STORE_BACKEND=faiss
   ```

**方案 B: 啟動 Milvus 服務並整合代碼**

優點:
- 持久化儲存
- 分散式擴展能力
- 適合生產環境

步驟:
1. 啟動 Milvus:
   ```bash
   # Docker Compose 方式
   docker-compose -f docker-compose-milvus.yml up -d
   ```

2. 整合 Milvus 到 `VectorStoreProvider`:
   ```python
   # app/Providers/vector_store_provider/client.py

   elif self.backend == "milvus":
       from app.Providers.vector_store_provider.milvus_client import get_milvus_client

       milvus_client = get_milvus_client()

       # 生成嵌入
       embedding_vectors = embeddings.embed_documents(texts)

       # 插入到 Milvus
       milvus_client.insert_vectors(
           file_id=file_id,
           texts=texts,
           embeddings=embedding_vectors,
           chunk_indices=[m.get('chunk_index', i) for i, m in enumerate(metadatas)]
       )

       store_id = file_id
       self._stores[store_id] = milvus_client  # 儲存引用
       return store_id
   ```

3. 實現 `similarity_search` 的 Milvus 分支

**方案 C: 使用 ChromaDB (替代方案)**

優點:
- 持久化儲存
- 較 Milvus 輕量
- 已有基礎實現

步驟:
1. 修改配置:
   ```python
   VECTOR_STORE_BACKEND: str = "chroma"
   ```

2. 安裝 ChromaDB:
   ```bash
   pip install chromadb
   ```
