# Prompt Response Fix - 20251126

## 問題描述

### 症狀
系統在回答問題時，第一句總是說「找不到相關內容」，但緊接著又提供了正確的答案。

**範例 1**：
- 用戶問題：「請說明LLM訓練分成哪幾個階段」
- 系統回覆：「在您目前選擇的文檔中，我沒有找到關於 LLM（大型語言模型）訓練階段的具體說明」
- 然後系統又提供了完整的訓練階段說明

**範例 2**：
- 用戶問題：「請說明民法概要」
- 系統回覆：「在您勾選的文檔中，我沒有找到直接相關的內容」
- 但後面的內容就是正確的民法概要答案

### 根本原因

在 `app/Services/prompt_service.py` 的系統提示詞（SYSTEM_PROMPT_TEMPLATE）中，第 4 點「誠實評估」的設計有問題：

```python
4. **誠實評估**：如果用戶勾選的文檔中確實沒有相關信息，可以：
   - 明確說明：「在您勾選的文檔中，我沒有找到直接相關的信息。」
   - 提供建議：「但根據問題的性質，我可以提供一些一般性的說明...」
```

這個提示詞讓 LLM 誤以為應該：
1. 先執行「誠實評估」步驟
2. 說明「找不到相關資訊」
3. 然後才提供答案

結果導致即使文檔中有相關內容，LLM 也會先說「找不到」。

## 解決方案

### 修改內容

**文件**：`app/Services/prompt_service.py`

**修改前**（第 42-51 行）：
```python
回答策略：
1. **直接使用上方文檔**：...
2. **優先引用文檔**：...
3. **智能補充說明**：...
4. **誠實評估**：如果用戶勾選的文檔中確實沒有相關信息，可以：
   - 明確說明：「在您勾選的文檔中，我沒有找到直接相關的信息。」
   - 提供建議：「但根據問題的性質，我可以提供一些一般性的說明...」或「建議您勾選其他可能相關的文檔。」
5. **準確性優先**：不要編造文檔中不存在的內容
```

**修改後**（第 42-52 行）：
```python
回答策略：
1. **直接使用上方文檔**：...
2. **優先引用文檔**：...
3. **智能補充說明**：...
4. **準確性優先**：不要編造文檔中不存在的內容
5. **重要：不要開頭就說「找不到」**：
   - ❌ 錯誤示範：「在您的文檔中，我沒有找到...（但實際內容如下）」
   - ✅ 正確做法：如果上方文檔有相關內容，直接回答問題並引用來源
   - 只有在上方文檔真的完全沒有任何相關資訊時，才說明找不到
```

同時也更新了英文版本的提示詞（SYSTEM_PROMPT_TEMPLATE_EN，第 147-157 行）。

### 關鍵改進

1. **移除模糊的「誠實評估」指令**：刪除了容易被誤解的提示
2. **明確禁止錯誤行為**：用 ❌ 和 ✅ 清楚說明什麼不該做、什麼該做
3. **提供具體範例**：讓 LLM 明確知道錯誤的回答模式
4. **調整順序**：將「不要開頭就說找不到」放在最後，作為強調提醒

## 測試建議

建議在以下場景測試新的行為：

1. **有相關內容的查詢**（如 LLM 訓練、民法概要）
   - 預期：直接回答，不說「找不到」

2. **沒有相關內容的查詢**（如詢問完全不在文檔中的主題）
   - 預期：明確說明找不到相關資訊

3. **部分相關的查詢**（文檔有部分但不完整的資訊）
   - 預期：引用文檔內容 + 補充說明，明確區分來源
