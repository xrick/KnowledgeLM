## 📝 內容描述

### 背景說明

目前每個用戶在每個 Skill 只能有一個對話 session。用戶希望能在同一個 Skill 下建立多個獨立對話，類似 ChatGPT 的對話列表功能。

### 目標

- 實作「建立新對話」功能
- 支援同一 Skill 下的多對話管理
- 提供對話列表與切換功能
- 支援對話重命名

### 範圍

- **包含**:
  - 「建立新對話」按鈕與 API
  - 對話列表 UI
  - 對話切換功能
  - 對話重命名功能
  - 刪除特定對話功能

- **不包含**:
  - 對話搜尋功能（未來版本）
  - 對話匯出功能（未來版本）
