## 處理流程總覽

```
上傳檔案
  │
  ├─ upload.py          → 驗證副檔名 (ALLOWED_EXTENSIONS)
  │
  ├─ config.py          → 檔案大小限制 (50MB)
  │
  ├─ input_data_handle_service.py
  │    ├─ .docx → extract_text_from_docx()   [python-docx]
  │    ├─ .pptx → extract_text_from_pptx()   [python-pptx]
  │    ├─ .txt  → extract_text_from_txt()    [built-in]
  │    └─ .md   → extract_text_from_txt()    [built-in, 共用]
  │         ↓
  │    chunk_text()  →  enrich_chunk_metadata()
  │
  ├─ file_metadata_provider/client.py → 寫入 SQLite metadata
  │
  └─ Vector Store (FAISS)             → 儲存 embeddings
```

## 各格式處理特點

### DOCX
- 使用 `python-docx` 的 `Document` 類別
- 提取所有段落文字，過濾空段落
- 支援密碼保護偵測（Traditional Chinese 錯誤訊息）
- 回傳 `(extracted_text, paragraph_count)`

### PPTX
- 使用 `python-pptx` 的 `Presentation` 類別
- 提取投影片中的 text frames、段落、表格內容
- 表格 cell 以 `|` 分隔
- 每張投影片標記 `[Slide N]`
- 回傳 `(extracted_text, slide_count)`

### TXT
- 使用 Python 內建 decode
- UTF-8 優先，Latin-1 作為 fallback
- 空檔案驗證
- 回傳 `(decoded_text, 1)`（視為單一 section）

### Markdown (.md)
- 與 TXT 完全相同的處理邏輯
- 不進行 Markdown 語法解析
- 保留原始純文字供 embedding 使用
